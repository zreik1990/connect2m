How it works

Three parts, all on your own network.

Set up your server

Run one script on a Windows PC. It becomes your connection server, sign-in and shared client list.

Install the Technician app

You and your team install it from the server's download page and start connecting.

Deploy the client

Install the client MSI on the PCs you support. Each shows its ID and a password only you know.
