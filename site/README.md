# connect2m product page

A standalone landing page for connect2m. Two ways to use it:

## Host it on GitHub Pages
1. Push this folder (already in the repo).
2. On GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a
   branch**, branch **main**, folder **/site**. Save.
3. Your page appears at `https://zreik1990.github.io/connect2m/`.

## Before you go live
Open `site/index.html` and replace the two checkout placeholders with your
store links (e.g. from Lemon Squeezy):
- `__BUY_URL__` — the single-PC $4.99 product
- `__BUY_URL_5PACK__` — the 5-PC pack

The app preview on the page is an illustration built in HTML, not a photo.
Once connect2m is running on a Windows PC, replace it with a real screenshot
for the most convincing page.
